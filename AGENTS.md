# Agent entrypoint — Vanya Arc brand

Read [the brand architecture](docs/brand-guidelines.md) and [product identity procedure](docs/product-identity.md) before creating or changing product branding. Keep the original V→A geometry and assets for Vanya Arc and UI unchanged. Every newly designed official product identity requires a distinct approved wave interpretation, matching favicon and semantic rationale. Preserve existing renderer behavior and require explicit identity changes. This public standalone tool must never contain actual consumer names, URLs, paths, marks, data, screenshots or origin evidence; use neutral examples and keep origin records outside. Preserve published assets until an explicit migration. Shared palette, typography and lockup API belong here; product-specific approved marks remain outside this public repository. Do not publish unapproved concepts or private material as real product assets. Run `npm test` and review the rendered lockup and favicon in both themes and monochrome; report unverified checks.
