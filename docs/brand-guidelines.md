# Brand Guidelines — Vanya Arc

## Архитектура

**Vanya Arc** — один источник идентичности. Продукт обозначается после слеша: **Vanya Arc / UI**. У другого продукта меняется только суффикс. Названия `Vanya-Arc` и сокращение `VA` не использовать как публичный вордмарк.

## Форма знака

Контур хранится в `src/mark.ts`, все SVG в `assets/` построены на нём. Короткий тёмный гребень → первая впадина → высокий тёплый гребень, единый непрерывный штрих; линейный градиент меняет цвет между 38% и 60% длины оси. Исходный `viewBox="75 115 540 235"`, толщина 29, скруглённые концы. Не изменять наклон, относительную высоту, направление, цветовые роли и непрерывность линии.

## Цвета и типографика

Палитра — только из `src/tokens.css`: `--ground`, `--ink`, `--ink-soft`, `--accent`. На светлой бумаге первый гребень тёмный, второй терракотовый; на тёмной поверхности первый светлый, второй тёплый. Монохром использует один цвет. `Vanya Arc` набрано Manrope 600 с оптическим трекингом ~-.048em, `/ UI`: второстепенный слеш и акцентный UI 700. Общий UI Manrope не обязан повторять плотный вордмарк.

## Понятные правила

- Не перекрашивай V и A отдельно: двухцветный знак уже задаёт эту связь.
- Не растягивай SVG, не отделяй половины, не используй внешнюю тень, обводку, градиент другого оттенка.
- В маленьком пространстве оставляй только знак; не уменьши вордмарк до нечитаемого.
- Не накладывай знак поверх разноцветного фона без контроля контраста. Для печати — монохром.
- Рекомендованная, пока не проверенная на всех носителях защитная зона — не меньше высоты видимого штриха около знака. Формальную минимальную ширину не объявляем, пока нет визуальных тестов.

## Код

Единственный экспорт: `@vanya/brand` + `@vanya/brand/tokens.css`. `@vanya/ui` только реэкспортирует это API. Статические носители в `assets/` — эталон для внешних сайтов. Настоящая CSS-палитра должна импортироваться до CSS, который использует токены.
