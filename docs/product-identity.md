# Проектирование индивидуальной айдентики продукта

Нормативная архитектура и палитра: [брендбук](brand-guidelines.md). Исходный V→A сохраняется для Vanya Arc и UI.

## Процедура для агента

1. Прочитать назначение сервиса, его аудиторию и ключевое действие. Проверить, существует ли уже утверждённый символ.
2. Сформулировать короткую связь смысла продукта с волной (ритм, импульс, периодичность, течение, развитие, фаза). При разработке нового знака предложить осмысленные направления геометрии и согласовать решение с владельцем. Для уже утверждённого знака сохранить принятое решение. Принцип свободной интерпретации волны допускает разные формы; фиксированные число гребней и пропорции исходного V→A действуют только для родителя/UI.
3. Проверить родство с семейством: пластика штриха, палитра из брендовых токенов, типографика Manrope, структура `Vanya Arc / Product`. Продуктовый знак должен визуально отличаться от исходного V→A и существующих продуктовых символов. Избегать универсальных клипарт-иконок и копирования чужой графики.
4. После утверждения владельцем сохранить исходную геометрию, SVG light/dark/mono и квадратный favicon, а также короткий rationale (смысл, дата/решение, источники и права). Индивидуальные артефакты и история решения остаются вне публичного пакета; здесь хранится общая рамка и базовый lockup. Новые официальные активы публикуются с явным правовым статусом.
5. Подключить свой символ через `productMark` у `VanyaArcLockup`; favicon должен представлять тот же продуктовый знак. Сохранить доступное имя и нативные ссылки. Проверить 16/24/32 px, обычный lockup, светлую/тёмную тему и монохром глазами. Зафиксировать результаты и нерешённые вопросы.

## Технический контракт

```tsx
import { VanyaArcLockup, type VanyaArcProductMarkProps } from "@vanya/brand";
import { ProductMark } from "./identity/ProductMark";
// ProductMark: React component accepting VanyaArcProductMarkProps
<VanyaArcLockup product="Product" productMark={ProductMark} />
<VanyaArcLockup product="Product" productMark={ProductMark} monochrome />
```

Продуктовый компонент использует SVG с viewBox, цвета из общих `--ink` / `--accent`, при `monochrome` — `currentColor`. В lockup символ декоративен, имя всего логотипа доступно как `Vanya Arc / Product`. Внешние применения символа получают собственное доступное имя. Без утверждённого символа временно используйте текстовый lockup (`showMark={false}`); статус айдентики PENDING. Прежнее поведение default сохраняется для совместимости старых вызовов; новая айдентика подключается явно. Старые версии пакета используют доступный API и отдельные утверждённые активы. Не выдавать условный пример за утверждённый знак. Не менять символы действующих сервисов без отдельной задачи.

## Критерии приёмки

- [ ] Связь формы с назначением продукта понятна и задокументирована.
- [ ] Геометрия индивидуальна и согласована владельцем.
- [ ] Палитра, типографика и структура имени соответствуют бренду.
- [ ] SVG / favicon согласованы между собой и читаемы в нужных размерах и темах.
- [ ] Источники, права и доступность проверены.
- [ ] Фактические визуальные результаты приложены; непроверенное обозначено NOT_VERIFIED.
